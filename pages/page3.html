新しいページ (ひな形)

ここに新しい教材ページを作ります。通信は次の3つだけ覚えれば使えます。

const comm = window.parent.comm; // マイコンへ1バイトずつ送信 (送り終わるまで待てる) await comm.sendBytes([240, 230, 2]); // マイコンから届いたバイトを受け取る window.addEventListener('comm-byte', (e) => console.log(e.detail.value));

接続ボタンは PAGE1 にあります。ページを増やすには index.html の PAGES に1行足します。
